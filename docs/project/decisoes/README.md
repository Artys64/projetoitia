# Decisões de arquitetura

Status: ativo  
Última revisão: 17/09/2026  
Responsável técnico: equipe do Support Hub

Crie uma decisão quando uma escolha técnica afetar mais de um componente, tiver
custo relevante de reversão ou substituir uma regra anterior. Use nomes como
`0001-titulo-curto.md`.

Modelo:

```markdown
# 0001 — Título

Status: proposta | aceita | substituída
Data: AAAA-MM-DD

## Contexto

Problema e restrições.

## Decisão

Escolha adotada.

## Consequências

Efeitos, limites e trabalho decorrente.
```
